# GenLayer Developer Onboarding Documentation

## Introduction
This documentation provides a structured onboarding guide for developers and beginners joining the GenLayer ecosystem. It covers account setup, wallet connection, dashboard navigation, task execution, and contribution workflow.

The goal is to reduce friction for new builders and improve developer experience during initial interaction with the platform.

---

## Prerequisites

Before starting, ensure you have:

- A Web3 wallet (MetaMask recommended)
- A GitHub account for submitting contributions
- Stable internet connection
- Basic familiarity with blockchain transactions and wallet signatures

---

## 1. Account Access & Authentication

### 1.1 Open Points Dashboard
1. Navigate to the GenLayer points platform - https://points.genlayer.foundation?ref=9S5B2F2Z
2. Click **Login / Get Started**
3. Select **Connect Wallet**

### 1.2 Wallet Signature
After connecting:

- Approve the wallet signature request
- This confirms wallet ownership
- No gas fee required

Failure to sign will prevent account activation.

---

## 2. Profile Configuration

After login:

1. Open **Profile Settings**
2. Connect the following identities:

| Integration | Purpose |
|------------|--------|
| GitHub | Required for builder submissions |
| Twitter/X | Used for social verification tasks |
| Email (optional) | Notifications & updates |

Ensure integrations are connected before attempting verification tasks.

---

## 3. Dashboard Overview

### 3.1 Task Categories

| Category | Description |
|----------|-------------|
| Social Tasks | Community engagement & identity verification |
| Platform Tasks | Interaction with GenLayer tools such as Studio |
| Builder Contributions | GitHub repos, tutorials, documentation improvements |

---

## 4. Completing Initial Tasks

### 4.1 Social Verification Tasks
Typical actions include:

- Joining Discord community  - https://discord.com/invite/qjCU4AWnKE
- Following official social accounts - https://x.com/GenLayerFDN
- Performing engagement actions

**Verification Workflow**
1. Perform action externally
2. Return to dashboard
3. Click **Verify**
4. Refresh page if status does not update

A task is only valid when marked **Completed**.

---

### 4.2 Platform Interaction Tasks

#### Open Studio Environment
1. Launch Studio from dashboard link
2. Connect wallet
3. Load sample project or contract

#### Execute Example Contract
1. Click **Run** or **Debug**
2. Confirm any wallet prompts
3. Wait for successful execution message

Return to dashboard and verify task completion.

---

## 5. Builder Contribution Workflow

Higher-tier rewards typically require ecosystem contributions.

### 5.1 Contribution Types

- Developer tutorials
- Documentation improvements
- Deployment walkthroughs
- Example contracts with explanations
- UX feedback or onboarding guides

### 5.2 Submission Process

1. Create public GitHub repository
2. Include clear README documentation
3. Add screenshots or usage explanation if applicable
4. Copy repository URL
5. Submit link via Builder Contribution section

Submissions should demonstrate practical value for new developers.

---

## 6. Best Practices for Developers

### Wallet & Environment
- Use a single wallet consistently
- Verify network before executing actions
- Avoid switching accounts mid-task

### Task Verification
- Always click **Verify** after completion
- Refresh dashboard if verification delays
- Keep screenshots for proof if needed

### Contributions
- Focus on clarity and reproducibility
- Provide step-by-step instructions
- Include expected results or outputs
- Prefer simple, well-documented examples over complex unfinished ones

---

## 7. Common Issues & Troubleshooting

| Issue | Possible Cause | Solution |
|------|---------------|----------|
| Task not verifying | Social account not connected | Connect account in profile settings |
| Wallet not detected | Wrong wallet selected | Reconnect using original wallet |
| Studio execution fails | Network mismatch | Confirm correct network & retry |
| Contribution rejected | Insufficient documentation | Add README details and screenshots |
